## แผนแก้ (เรียงตามลำดับที่แนะนำ)

### 0. แปลบรรทัดบทสนทนาที่หลุด (ทำได้ทันที)
* ไฟล์ `work/tr_new_dialogue.tsv` (60 แถว) — แปลคอลัมน์สุดท้าย ใช้กติกาเดิม (`*` ขึ้นบรรทัด, `@@…@@` คงไว้)
* รวมเข้า master: `python -I -X utf8 tools/tr.py import <โฟลเดอร์> work/strings_master.tsv` (หรือรวมแถวเข้า master ตรงๆ)
* หรือใช้ `tools/tr.py export` ใหม่ทั้งชุด: แถวที่แปลแล้วจะเติมให้อัตโนมัติ เหลือว่างเฉพาะ 60 แถวนี้

### A. KINDLE.BIN — ชื่อในการต่อสู้
1. ถอดรูปแบบ: หัว `FS2KindleTable` + u32 @40 = 849, 1429 … → น่าจะเป็นตารางระเบียนขนาดคงที่ (ชื่อ 夏皓 อยู่ที่ระเบียนแรก) — วัดระยะห่างระหว่างชื่อ หาขนาดช่องชื่อ (แบบเดียวกับ Objects/FS2_Items)
2. เพิ่มใน `tools/fstables.py` (FIXED หรือ MULTI) + self-test round-trip
3. ชื่อซ้ำกับ `Objects.bin` → ใช้คำแปลร่วมกันอัตโนมัติ (by_src) ไม่ต้องแปลซ้ำ เหลือเฉพาะชื่อที่ไม่ซ้ำ (ชื่อท่าศัตรู, 我方虛擬 ฯลฯ)
4. ทดสอบ: ฉากต่อสู้ — ชื่อใต้รูป, ป้าย "张婕 反弹攻击" (ส่วนชื่อ), เมนูเป้าหมาย

### B. ป้ายชื่อ NPC เหนือหัว + ชื่อในเซฟ
1. ชุดทดสอบ log_drawtext=1 เดินเข้าบ้านพระเอก (夏皓屋) ดู 范氏 / 旺财 ว่าถูกวาดเป็นข้อความจีนธรรมดา (ไม่ใช่คีย์) แล้วไล่ว่ามาจากไฟล์ไหน:
   * ถ้าเป็นคีย์แต่ไม่ขยาย → ปัญหา proxy
   * ถ้าเป็นจีนตรงๆ → หา source: `Objects_Back.bin`, KINDLE.BIN, ข้อมูลแผนที่ (`Map/` หลวม), หรือเซฟ
2. **ชื่อในเซฟเก่า**: เซฟที่สร้างก่อนลง mod เก็บชื่อจีนไว้ — แก้ได้ 2 ทาง
   * (ง่าย) บอกผู้เล่นให้เริ่มเกมใหม่ หรือรอให้เกมเขียนชื่อใหม่ (ถ้าเกมโหลดชื่อจากตารางทุกครั้งที่เข้าทีม)
   * (ดีกว่า) ให้ proxy แทนที่ชื่อจีนตอนวาด: เพิ่มชื่อตัวละครหลัก (夏皓 张婕 默心 嘯月 瞳影 …) เข้ากลไก "drawn-text replacement" (`FS3_TH_exe.txt`) ทำงานกับข้อความที่เกมวาดทั้งบรรทัดเท่านั้น → ใช้ได้กับชื่อบนป้าย/หน้าสถานะ แต่ไม่ได้ถ้าชื่ออยู่กลางประโยค (ประโยคพวกนั้นเป็นคีย์อยู่แล้ว)
   * (ทางเลือก) เครื่องมือแปลงไฟล์เซฟ: แทน Big5 ของชื่อด้วยคีย์ — ต้องถอดรูปแบบเซฟ เสี่ยงทำเซฟเสีย ไม่แนะนำ
3. `FS2_RoleManDefault.Bin`: ตรวจว่าเริ่มเกมใหม่แล้วชื่อพระเอกมาจากไฟล์นี้หรือ Objects/KINDLE — ถ้าใช่ export เพิ่ม

### C. FS3Maps.BIN — ชื่อสถานที่
1. หัว `FS3SmallMapLink` u32 @40 = 306 รายการ ตามด้วย `FS3-…` (ชื่อไฟล์แผนที่) → ระเบียนขนาดคงที่ที่มีชื่อไฟล์ + ชื่อสถานที่
2. เพิ่มใน fstables, export, แปล (ชื่อสถานที่ควรตรงกับที่ใช้ในบทสนทนา — ใช้ glossary/ชื่อที่ผู้แปลใช้แล้ว)
3. ทดสอบ: ป้ายมุมขวาบน, เซฟใหม่ (ช่อง "สถานที่"), แผนที่ใหญ่, ป้ายเดินทาง
4. อาจต้องเพิ่ม `wrap_rules` ให้ป้ายมุมขวาบน (กรอบแคบ)

### D. ไฟล์ข้อความอื่น

| `FS2_Narrate.bin` | หัว `FS2NarrateLetter` u32 = 66, 66 → น่าจะเป็นตารางออฟเซ็ต 66 ข้อความ (แบบ ItemHelp) — ข้อความบรรยายยาวและเครดิต; เครดิตอาจคงจีนไว้หรือแปลชื่อตำแหน่ง |

### E. ตรวจซ้ำแบบอัตโนมัติ (กันตกค้างในอนาคต)
1. เครื่องมือ `tools/find_untranslated.py`: สแกนทุกไฟล์เกม หาข้อความ Big5 ที่ไม่มีใน master (ใช้ตรรกะเดียวกับการสแกนครั้งนี้) → รายงานต่อไฟล์
2. ชุดทดสอบ "หาจีนบนจอ": เล่นด้วย `log_drawtext=1` แล้วให้สคริปต์ดึงทุกข้อความจีนที่ถูกวาด (ไม่ใช่คีย์) จาก log → รายการข้อความที่ผู้เล่นเห็นจริงแต่ยังไม่แปล พร้อมตำแหน่งบนจอ — แม่นกว่าการสแกนไฟล์ เพราะตัดข้อมูลที่ไม่ได้ใช้ออก
