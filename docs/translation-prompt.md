# รูปแบบไฟล์ (TSV, UTF-8, คั่นด้วย TAB)
member <TAB> block <TAB> offset <TAB> source <TAB> thai
- ห้ามแก้คอลัมน์ 1–4 แม้แต่ตัวอักษรเดียว ห้ามเพิ่ม/ลบ/สลับแถว ห้ามเว้นบรรทัด
- เติมเฉพาะคอลัมน์ที่ 5 (thai) ในแถวที่ว่าง ถ้ามีคำแปลอยู่แล้วให้คงไว้ ห้ามเขียนทับ
- ส่งกลับเป็นไฟล์ TSV ครบทุกแถวในรูปแบบเดิม ไม่ต้องอธิบายอะไรนอกไฟล์ (ถ้ามีข้อสงสัยให้ใส่ไว้ท้ายคำตอบแยกจากไฟล์)

# รหัสพิเศษ (ต้องคงไว้ครบ ตำแหน่งย้ายตามคำที่มันครอบอยู่ได้)
- * = ขึ้นบรรทัดใหม่ ใช้เฉพาะตอนจบประโยคหรือจบคำพูดตามธรรมชาติ ไม่ต้องตัดกลางประโยคเหมือนต้นฉบับ (ระบบตัดคำและขึ้นบรรทัดเองอยู่แล้ว)
- @@W(2)@@ @@w(1)@@ @@rw@@ @@RW@@ และรหัสอื่นที่ขึ้นต้นและลงท้ายด้วย @@ = รหัสควบคุม (สี/หยุด/ไฮไลต์ชื่อ) คัดลอกตัวอักษรให้ตรงเป๊ะ ห้ามแปล
  ตัวอย่าง: 在@@w(1)@@客棧@@rw@@等你 -> รออยู่ที่@@w(1)@@โรงเตี๊ยม@@rw@@ (แปลเฉพาะคำภายใน ห้ามให้รหัสหายหรือเพิ่ม)
- %s %d และรูปแบบ % อื่นๆ = ค่าที่เกมใส่ให้ ต้องมีครบทุกตัว ลำดับเดิม ห้ามแปล
- เครื่องหมายแบบจีน: ！→ ! ？→ ? ～→ ~ （）→ () …→ ... ส่วนจุดไข่ปลาที่ล้วนๆ ทั้งแถว (………) คงไว้
- ห้ามใส่ | ระบบตัดคำให้เอง

# สไตล์การแปล (สำคัญ)
- สำนวนไทยแบบนิยายจีนกำลังภายใน/สามก๊กฉบับแปล: สุภาพ มีกลิ่นโบราณ แต่อ่านง่าย ไม่ใช้ภาษาพูดสมัยใหม่/คำสแลง
- สรรพนามตามบริบทและฐานะผู้พูด: ข้า/เจ้า (เสมอกันหรือผู้ใหญ่พูดกับผู้น้อย), ท่าน (สุภาพ), ข้าน้อย/ขอรับ (ผู้น้อยต่อผู้ใหญ่),
  คุณชาย, แม่นาง, ท่านอาจารย์, ศิษย์พี่/ศิษย์น้อง, พี่ชาย/พี่สาว, ใต้เท้า (ขุนนาง), ท่านแม่/ท่านพ่อ
- ตัวละครหญิงใช้ "เจ้าค่ะ/เพคะ" เฉพาะเมื่อฐานะเหมาะสม ส่วนใหญ่ใช้ภาษากลางๆ แบบนิยายจีน ไม่ใช้ "ค่ะ/คะ" ธรรมดา
- รักษาน้ำเสียงตัวละคร (เช่น ตัวร้ายผู้ลีลาอ่อนช้อยพูดลากเสียง ~ , เด็กหนุ่มห้าวๆ, หมอสุภาพนิ่งๆ) ตัวอย่างข้อความต่อเนื่องในไฟล์เดียวกันคือฉากเดียวกัน ให้อ่านทั้งไฟล์ก่อนแปลเพื่อให้ต่อเนื่อง
- ชื่อตำแหน่ง/ราชวงศ์/สถานที่: ใช้คำเรียกที่คนไทยรู้จักจากสามก๊กก่อน (เช่น ลกเอี๋ยง/ลั่วหยาง ใช้ตามหมวดข้างล่าง)
- ประโยคสั้นๆ เช่น 嗯 / 好 / 是 ให้แปลสั้นเท่าต้นฉบับ

# ความยาว
- ช่องข้อความแสดงได้ราว 3–4 บรรทัด บรรทัดละประมาณ 22–25 ตัวอักษรไทย ต้นฉบับแถวหนึ่งไม่เกิน 4 บรรทัด จีน 21 ตัวต่อบรรทัด
- ภาษาไทยยาวกว่าจีนประมาณ 1.5–2 เท่า ให้กระชับ ตัดคำฟุ่มเฟือย ความยาวรวมต่อแถวควรไม่เกินประมาณ 90 ตัวอักษร ถ้าต้นฉบับยาวมากให้สรุปใจความโดยคงความหมายสำคัญ
- รายการ ชื่อไอเทม/สกิล/เมนู (ไฟล์ Objects, FS2_Items, FS2_Fighter, Message, DefaultString) ต้องสั้นที่สุดเท่าที่ได้ ห้ามเกินความกว้างของต้นฉบับมากนัก
  (ชื่อไอเทม ≤ ~12 ตัวอักษรไทย, ชื่อสกิล ≤ ~10) และคำอธิบาย (FS2_ItemHelp, FS2_FighterHelp) ≤ ~60 ตัวอักษรต่อบรรทัด
- ต้นฉบับที่สั้นมาก (1–2 ตัวอักษรจีน เช่น 嗯 好 是 對) ให้ใช้คำแปลชุดเดิมซ้ำกัน (เช่น 嗯=อืม, 好=ตกลง, 是=ขอรับ/ใช่) อย่าคิดคำใหม่ทุกครั้ง
  เพราะระบบรองรับคำแปลสั้นที่ไม่ซ้ำกันได้จำกัด (~100 แบบ)
